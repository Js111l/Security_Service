## General Info  
This repository contains the code for Security Service - one of the core microservices of **Shopiqo**, a full-stack e-commerce platform. 
The Security Service is developed using Java and Spring Boot. Service is responsible for user authentication, as well as handling secure user login and registration functionalities.
Redis cache is used for storing user session information.
